## 6. 本会话修过、容易再踩的坑

### 6.1 GitHub「一堆红」

`main` HEAD 是绿的。红的是 **P4–P8 当时合进去的旧 SHA**、Actions 历史、已合并 PR 页上的旧 checks。GitHub 不会把旧提交改绿。不要改历史、不要重跑旧 SHA 当修复。

可删的只有**已合并仍留在远端的 feature 分支**。不能删：`main` 提交、已合并 PR、Actions 记录、任何 `v*.0` 标签。六月草稿 PR **#21 / #23** 与这次红叉无关，先别动。

判断当前要不要修：只看 **`main` 最新提交**的 checks。

### 6.2 PDF 导出 `No CJK font found`

已修（#235）。渲染器会找 Linux WenQuanYi、macOS 苹方、Windows 雅黑，可用 `COLD_STORAGE_CJK_FONT_PATH` 指定文件，再不行用 PyMuPDF 内置 `china-s`。生产镜像也装了 `fonts-wqy-zenhei`。代码：`backend/src/cold_storage/modules/reports/renderers/cjk_font.py`。

CI 有 WenQuanYi 时仍优先它，避免 PDF 字形黄金测试漂移。

### 6.3 草稿导出投资分项

TD-022 已修（#234）。计算器同时发 `item_key` + 中文 `item_name`；报告用 `backend/src/cold_storage/modules/reports/application/investment_item_keys.py` 解析。目录 zh-CN / en-US 两边都要有对应 `investment.<english_key>`。未知中文名 fail-closed（`UNKNOWN_INVESTMENT_ITEM_KEY`），组装可用 `skip_unprojectable_sections` 跳过整段而不是 500。

**不要**在 `reports/application` 的注释里写 `cold_storage.modules.calculations` 这个字符串。

### 6.4 Snapshot `extra_forbidden`

分区快照曾因 `frozen_deduction_ratio`、`packaging_area_factor_k` 被拒；投资快照曾因 `item_key` 被拒。处理方式：在模型上加**可选字段**，不要 `extra="allow"`。
