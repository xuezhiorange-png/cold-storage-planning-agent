## 安全边界

- 原始端点按其 IEEE 值转成有理数；不做几何吸附、舍入连接或未知缺口桥接。
- 门洞桥接仅连接选定源墙段的真实开放端点，另绑定原图门扇、原始三次曲线、
  可视复核依据。它只表达拓扑参考，门型不换算成净宽。
- 突出角部的边界分段仅采用**其他源路径的精确端点**：必须严格落在被分段的
  原始线段上。保留原线、分段来源和原始矩形；不修改 PDF，不任意裁剪墙线。
- 非正交边、曲线墙线不近似为矩形；保留来源并拒绝本正交拓扑工具计算。
- 重复、相交、T 形分支、多环/井道、零长线和未知开口均不能静默获得闭合。
  多环未实现可靠分解时直接阻断面积，不忽略内环。
- 图面人工选取仍可能有语义错误。样式、平行线和 Hash 都不是建筑语义或批准证明；
  未复核向量保留 `UNCLASSIFIED_VECTOR`，不宣称对 80,279 条路径全量自动分类。
