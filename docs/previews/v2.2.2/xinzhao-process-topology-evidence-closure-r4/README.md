## 几何与门洞检查

新增的 `offline_evidence_closure.py` 只有小范围离线检查：

- 直接消费经过明确复核的原始线段，调用冻结 R2 拓扑检查；不生成缺失线段、不吸附、不移动坐标。
- 对已闭合正交环，用原核心相交检查加精确射线包含关系区分相离、接触、交叠、嵌套与外部环。
- 分开输出外环参考面积、内环图形面积；内环类型未确认时，占用面积、扣除后面积、装修净面积均为 `null`。
- 目标六处既有门洞额外核查源门图示的局部位置与开口投影，不再只检查“路径存在”。
  空间兼容不是门身份自动批准；仍需原图局部视觉核对。北门完整门扇细节保持未核实。
- 门型代码不推导净宽，所有正式净宽仍缺失；共享墙、源门洞和实际可通行路线不混用。

原有 R3 双侧门框端帽与独立房间选择重新核验；没有新增不相关的重复门洞绑定。
成品间双环虽具有可验证的拓扑关系，仍没有适用的建筑空间类型／面积扣除依据。
输出外环图形面积不代表完整房间面积验收。
