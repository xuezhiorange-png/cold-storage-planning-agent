# Owner V2 分选包装间几何与面积校准 R1

任务：`V2_2_2_OWNER_V2_PACKAGING_AREA_GEOMETRY_CALIBRATION_R1`。核验基线：`15d2d7759bc0192813122c7aba16dcc11e4be0cd`；研究日期：2026-10-19。仅离线研究与只读回算，不启用新版 P1。

## 工程审核结论

**已证明旧公式和 V2 定员/台数计算；尚不能批准新版包装间面积。** 当前缺少本项目设备总图、三人作业布置、物料周转及独立通行空间。旧 5.6/3.0、8.0/7.6、1.1 的数学用途明确，但没有足够资料将其拆解为经审核的本项目工位模块。不能用既有房间几何 PASS 代替设备、作业和物流布置 PASS。

### 八个问题的直接回答

1. **5.6m、3.0m是什么？** 生产代码把它们用于纵、横排布节距，不是已选设备台面的实际长宽。16.8m²是节距乘积；历史字段 `packing_table_area_m2` 的名称不能使其成为设备本体面积证据。
2. **8.0m、7.6m怎样组成？** 源码写作 `3.0+5.0`、`3.0+4.6`。没有可追溯总图说明各项对应哪条通道、设备边界或操作面，不能擅自把这些加数命名为净通道。代数重写为 `L=5.6*n_long+2.4`、`D=3*n_short+4.6` 也不能证明2.4/4.6就是外围净距。
3. **每台3人的空间依据充分吗？** 3人/台是 Owner V2 已确认业务政策；三人分别站在哪侧、触及范围、包装供给/出料、并行动作尚无本项目布置依据。厂商四人旋转台、通用不锈钢台都不能替代本项目三人工位验证。
4. **两班共用需要什么？** 同一批台位按峰值并发人数确定；必须审核交班清洁、设备实际可用时间、库存/包材补给和交接缓存。非重叠班次不等于生产期不同用途的空间可以互相覆盖。
5. **旧排布适合V2吗？** 只能作为显式条件投影工具。它不输出设备、操作、物料路径、门扇或工位坐标，不能证明连续生产线、避让人员或包材补给合理；因此尚不能作为新版面积消费者。
6. **1.1仍有依据吗？** 旧P1C/ADR-044有明确历史长边Authority，保留有效；其物理构成及对V2的适用性未获验证，不能视为普适建筑/物流余量，也不能长宽重复乘1.1。
7. **新版怎样计算？** 从有来源的设备及三人操作包络出发，明确供料、出料、独立通行、清洁检修和状态共享，再形成真实排布、几何并集及建筑外包络；独立核查Portal和物流路径。参数化草案见[校准方法](layout-geometry-calibration.md)，未填物理默认值。
8. **哪些资料缺失就不能形成正式P1面积？** 设备型号/总图、三人任务/站位、供料出料及周转容器、输送线/缓存、通行/门洞净空依据、清洁检修/交班状态、外围与建筑净尺寸口径，以及新版排布和余量Authority审批。见[Owner决策矩阵](owner-decision-matrix.md)。

## 旧排序的真实行为

搜索 `n_long=1..n_need+199`、`n_short=1..n_long`，格位必须不少于需求。优先级依次为：格位轴比在1.67～2.40、空格最少、距2.0最近、原始面积最小；同rank保持原循环首项。

20台时选7×3，尽管同一有限搜索域存在5×4、20格、原始504.64m²的组合。原因是格位轴比先于空格和面积排序；并非全局面积最优算法。不能因此批准5×4：其站位、连续物流及Portal避让未验证。18台和28台在该有限域的选择恰好也是原始面积最小，但仍不构成工程最优证明。

格位比7/3约2.333，不等于原始建筑比41.6/13.6约3.059，更不等于P1C比45.76/13.6约3.365。有限搜索上界是实现边界，不是工程容量定理。完整比较见[审计JSON](legacy-geometry-authority-audit.json)。

## 八套真实布局只读复核

8套分选包装间均为名义45.76×13.6m、旋转0°、实际面积622.336m²。本次从封存JSON恢复48条真实接口，对实际墙线、Portal长度和边面分类作精确整数毫米核对；没有重新运行Access。

每套都有更衣人员、包材、一级预冷、冻结、二级预冷水果及二级预冷房间相关接口，均为记录中的Direct Shared Edge。包材接口保持“包材库长边→分选包装短边”、STRAIGHT_ONLY及原净宽。坐标、Portal、路线、相邻房间和每个SVG SHA256均见[逐套完整复核](real-layout-interface-review.json)。

更衣人员接口并不是场地入口；场地到更衣的路线不在本次室内台位复核中重新搜索。直接共边路线长度0不意味着室内人员/物料走行距离0。没有站位/设备模型，不能认定这些门口不会被台位或周转货物阻挡。既有P1C长宽正确不代表工位功能可用，旧几何不重绑定到V2。
