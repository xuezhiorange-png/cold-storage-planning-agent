# H5 两班完整更衣流程 R11 R6

## 结论

本次没有证明完整班次更衣功能可用。实际功能保持 INPUT_REQUIRED，不得升级为 CONDITIONAL_FIT。
原两班各53人、22列110格、P01/P02同一H5矩形和两处真实1500mm Portal不变。未进行Native、MAIN或任何授权槽操作。

## 28次批次转换与完整流程不是同一件事

原4柜前/6座方案：30个原静态批次；独立核验全部28次相邻转换，通过28次。每次保持53人身份，逐人移动；坐姿起身/坐下采用三维上身联合包络与前伸腿部，座凳始终参加碰撞检查。
两班各53人的独立进室、独立离室路径通过条件几何检查。外部Access仍为原档参考，未重新证明外部人流能力。
完整轨迹从东入口逐人到本位开始，进入柜前操作，再去更衣区、座凳、起身返回。保持53人在室直到全员完成服务，再安排南门离室。当前保守协议每班仅3人完成服务链，第4人服务区让位时无空闲已验证普通本位，立即阻塞。50人未完成，完整班次时间不可计算。
这是该明确调度协议与当前本位分配的阻塞，不是证明H5所有调度都不可行。没有将独立进入/离开、独立28次转换拼接成虚假的完整成功。

## 可审阅的人员活动假设

原400×600mm身体、20mm相邻间隙保留为对照。固定全部坐标后，对身体周边外扩0/10/25/50/100mm：10mm即出现侵入净通道或坐姿支撑模型边界等冲突，25mm出现相邻人员活动包络重叠。静态不重叠不能证明穿脱衣、弯腰取物或转身可用。
坐起的保守模型：上身从座面高度起覆盖原坐姿至前方站姿的联合空间，腿部始终在座凳前缘外；额外50mm侧向/前向余量仅为假设。不能视为生物力学、平衡或个体适配证明。

## 时间与吞吐边界

示例：步行600mm/s；柜前20s；更衣90s；座凳45s；坐下4s、起身4s。均未经批准。记录逐项路径长度/速度和动作时长的累计已完成前缀。失败步骤没有完成时间。
一个更衣操作位、53人、每人90s，仅此资源的理想工作量下界已为4770s（79.5分钟）。这还没有计入步行、排队或冲突，且不代表本方案能完成。60/90/180s敏感性保存在timing-hypotheses.json。没有认可的时间输入时，模块返回INPUT_REQUIRED与空时长。
柜前15批来自各柜列与层位分配，不能用简单人数相除替代实际动作序列。资源下界只作下界，完整时长只允许从所有进入、使用、离开步骤均通过的连续轨迹计算。

## 工程建议及缺失输入

优先审阅服务区/等候本位的轮换协议与更衣操作位数量，再确定座凳和柜前并发人数；不能把座位占用者固定在公共服务设施上，又假定其随时能让位。当前串行更衣单工位是时间瓶颈，新增座位不能自动解除。
真实人体活动尺度、衣物与五层格口可达性、坐起包络、实际柜型与房门开向、净通道/装修完成面、批准的洁污流线、清洁维护空间、全班允许时窗及经审阅的操作时间均待确认。
全部结论限于假设模型。R1–R5代码及历史工程有效状态、P1、Stage B与九/十二指标未改。
