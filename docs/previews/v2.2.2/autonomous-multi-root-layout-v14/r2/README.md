## 实现

- 在部分房间DFS中检查当前完整P1网格；四方向、两种原托盘朝向、原50mm载荷边缘余量及3000/5000mm主通道均保留。有限网格模板失败不等于所有连续物理布置不可行。最终有序取放重新验证。
- 同房间尝试设备组反射、实际障碍边缘位移、原尺寸折箱机转向和人员操作位重排；所有设备、53个包装人员站位、14缓冲位、6线端托位保留。原排序模板与预冷模板仅提取为可复用函数，默认输出回归不变。
- 近端设备、一级/二级预冷或覆膜失败可获得自己的局部选项，避免四个候选名额全被分选包装变体占用。失败端点保留实际矩形、停靠检查、所需主通道及邻接目标。
- 门洞从原合法边与实际通道交点搜索，保留P1边类、净宽和原安全谓词。先过滤真实不可用外侧站位，再有界排列候选对；预算耗尽不再进入未计入该预算的旧回退搜索。
- 柔性覆膜间的6种断面由现有设备和作业需求派生；失败门洞反馈为相关房间/通道的实际对齐目标，精确空洞反馈为相关房间的连接调整。目标仍是搜索偏好，不是新的坐标硬锁。
- 已过必要检查的完整失败根优先于早期容量/安装失败，同时维持三类结构的公平搜索配额。
- 工艺合格、物理不同、核心关系不同、实质差异分别判断。同组织变体、整体平移/镜像、仅覆膜连接及下游延长均不能占用新增组织名额。原九/十二比较器未修改，不跨7/8天宣称正式Pareto。
