# 项目工程资料索取清单

当前未找到可用于项目工位准入的已审核设备及三人作业资料。禁止用历史节距或合成示例填空。

| FIELD | REQUIRED_DOCUMENT | WHY_REQUIRED | ACCEPTABLE_EVIDENCE | CURRENT_STATUS | AFFECTED_CALCULATION |
|---|---|---|---|---|---|
| PROJECT_AND_FACTORY_ID | 项目工艺设计条件及设备适用性说明 | 防止跨项目套用 | 具备项目身份和版本的设计文件 | UNAVAILABLE | 全部诊断 |
| EQUIPMENT_BODY_LENGTH_WIDTH_HEIGHT | 设备总图及型号规格书 | 设备实体及高度独立记录 | 带尺寸标注、图号、修订版的总图；不可按图片像素估算 | UNAVAILABLE | 设备实体包络 |
| SELECTION_EVIDENCE | 选型评审或批准记录 | 公开参考与项目选型不同 | 可核实的既有审批文件；文件Hash不替代审批 | UNAVAILABLE | 选型状态记录；适配器无批准权 |
| INFEED_OUTFEED_REJECT_INTERFACES | 输送接口及物流图 | 进料、包材、成品与剔除物分别连通 | 有局部坐标和设备方向的接口尺寸 | UNAVAILABLE | 物料路径 |
| THREE_OPERATOR_TASKS_AND_POSITIONS | 三人任务及站位布置图 | 3人/台不等于站位已可用 | 每人任务、站位、朝向、动作区、入口路径的工艺复核 | UNAVAILABLE | 三人适配 |
| MATERIAL_CARRIER_ENVELOPES | 周转箱、车及包材规格 | 物料占用独立于设备尺寸 | 型号、外廓、运输方式和使用状态 | UNAVAILABLE | 供出料占用 |
| PERSONNEL_AND_MATERIAL_ROUTE_WIDTHS | 通道与净空设计条件 | 历史房间Portal不证明室内净宽 | 分别有来源的路径中心线、全宽与净空要求 | UNAVAILABLE | 全宽扫掠校核 |
| FOUR_STATE_OCCUPANCY | 生产、交班、清洗、检修工况图 | 非同时不等于自动允许共用 | 设备常驻、开启范围、共享条件及审核记录 | UNAVAILABLE | 工况碰撞与共享复核 |
| SHIFT_CHANGE_CLEANING_DURATION_BUFFER | 交班清洁SOP及生产节拍 | 不得默认零耗时或零缓冲 | 独立确认时长、人员、物料与状态 | UNAVAILABLE | 时间空间共用 |
| MAINTENANCE_ACCESS_AND_GUARD_SWING | 维护手册与护罩开启图 | 设备本体不包含检修空间 | 明确检修侧、开门包络、所需通行 | UNAVAILABLE | 清洁检修 |
| ROOM_CLEAR_AND_PORTAL_BOUNDARIES | 建筑净尺寸及工艺接口图 | 房间外包络不等于净可用面积 | 带墙体、门、障碍及Portal身份的设计资料 | UNAVAILABLE | 18/28台适配仍未评价 |

私有采购协议、图纸原件仅存本地获授权证据目录。公开仓库只保留允许公开的脱敏字段和Hash。审批记录需人工核实；本适配器不能授予选型或工程批准。
