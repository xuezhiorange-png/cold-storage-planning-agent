V2.0 的 factory power 结果仍是概念设计阶段的估算工厂电功率，单位为 `kW`。
它不是 `kWh`，不是电表计量值，不是月度电费，不是变压器选型，不是正式配电设计，
不是短路计算，不是电缆选型，也不是保护整定。产品仍不替代注册工程师、设计院或正式
电气设计。
