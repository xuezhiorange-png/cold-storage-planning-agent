## 新策略：需求归一化半周长平方

新增 `infrastructure/stage_b_area_efficiency.py`，复用原物理 w/d、Minimax 的最差
房间聚合、既有公平调度、首次严格改善见证回调、精确见证切除和累计账本。
不叠加墙线、面积和比例的任意加权总分，不改原模型硬约束。

对房间 i，实际宽深为 w/d，P1 需求为 A：

`C_i = (w+d)^2 / (4*A) = (actual_area/A) * (aspect+2+1/aspect)/4`。

使用单一软目标 `min max_i ceil(1000*C_i)`。整数 mm² 分母复用原模型的需求向上
取整，诊断另外保留 P1 原始精确需求。1000 仅是表示精度，不是工程阈值。
三房间均归一化到自身 Authority 需求，没有由调用方提供的目标面积或权重。

性质：固定需求下整体放大房间会增加该代理，而纯比例 Minimax 对同形放大无感。
AM-GM 给出 `actual_area <= (w+d)^2/4`，因此代理的任一固定子水平集也约束实际
面积的增长；这是一条数学性质，不是在模型中增加面积上限。不同房间仍可能
存在目标平坦区，表示精度存在并列，第一可行停止也不保证最优。

**不能保证所有首个有效房间都紧贴需求面积。** 强制保证需要硬约束，而本轮未
获此授权。该策略只修正无界放大不受惩罚的偏好；是否改善真实布局仍未评估。
新增平方定义可能影响传播成本，实际 Native 效率也未评估。

`apply_area_efficient_guidance` 只增加总定义变量和等式。原物理赋值均有唯一扩展；
不增加最小宽度、最大比例、面积上限、固定位置或新的物理切除。正整数域与
int64 支持范围在修改模型前核查，不通过截断域解决溢出。Work 按整批预检查。

`StageBAreaEfficientQualityFairSearchSolver` 显式启用；第一阶段应用此软目标，
第二阶段复用同一模型、同一代理及剩余公平份额。没有附加求解、配额或阶段
重置。UNKNOWN 不切除、不改称 INFEASIBLE、不自动重试。原始有效基线不替换。

## 面积独立诊断与版本化比较

`area_efficiency_snapshot` 调用原几何/路线/建筑诊断，校核候选来源 Hash 与当前
绑定一致，从 P1 读取需求、从实际物理 w/d 计算面积；独立暴露需求、实际面积、
面积倍数、超配比例和不足面积，不使用演示数据填充。Coating 仍为包装箱封膜间。

原 `same-handoff-exact-nine-metric-pareto@1.0.0` 及函数完全不变。
新增 `same-handoff-nine-metrics-plus-three-area-allocations@1.0.0`：
先复用原九指标、同 Authority/同 Handoff/同 V2 的可比性，再增加三个房间的
面积倍数作为独立不恶化指标。新十二指标 Pareto 才可更新本次已验证 Hint；
原九指标改善但任一房间面积倍数增加只能是取舍，不能隐藏在“Pareto 改善”中。
缺失/冲突/不足面积/身份不符均不判 Pareto。它不是功能适用性或 P2D 验收。

本版本使用精确面积，不私加面积容差。例如 R4 01→02 原九指标 Pareto 评价保持
原样，但 Coating 实际面积增加 0.000714m²，新十二指标会标为 Tradeoff。这是
明确版本化的保守比较，不是将历史实验改判失败；也可能因此减少 Hint 更新机会。
